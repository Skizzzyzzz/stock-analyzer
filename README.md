# Stock Analyzer 📈\n\nA real-time stock analysis application that fetches data from Yahoo Finance, performs technical analysis, and provides buy/sell/hold signals.\n\n## Features\n\n- ✅ Real-time stock data from Yahoo Finance API\n- ✅ Technical analysis with RSI and Moving Averages\n- ✅ Buy/Sell/Hold signal generation\n- ✅ Top 10 popular stocks tracking\n- ✅ Individual stock search\n- ✅ SQLite database for caching\n- ✅ Modern responsive web interface\n- ✅ RESTful API backend in C++\n\n## Architecture\n\n### Backend (C++)\n- **API Client**: Fetches stock data from Yahoo Finance using libcurl\n- **Analyzer**: Calculates RSI, Moving Averages, and generates trading signals\n- **Database Manager**: SQLite integration for data persistence\n- **REST API**: Crow framework for HTTP endpoints\n\n### Frontend (JavaScript)\n- Clean, modern UI with real-time updates\n- Stock search functionality\n- Statistics dashboard\n- Responsive design\n\n## Prerequisites\n\n### macOS Installation\n\n```bash\n# Install Homebrew if not already installed\n/bin/bash -c \"$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)\"\n\n# Install required dependencies\nbrew install cmake\nbrew install curl\nbrew install sqlite3\nbrew install nlohmann-json\n\n# Download Crow (header-only library)\nmkdir -p backend/libs\ncurl -L https://github.com/CrowCpp/Crow/releases/latest/download/crow_all.h -o backend/libs/crow_all.h\n```\n\n## Building the Project\n\n```bash\n# Navigate to backend directory\ncd backend\n\n# Create build directory\nmkdir build && cd build\n\n# Configure with CMake\ncmake ..\n\n# Build the project\nmake\n\n# Run the server\n./stock_analyzer\n```\n\nThe server will start on `http://localhost:8080`\n\n## API Endpoints\n\n### GET `/api/stocks`\nFetch and analyze top 10 stocks\n\n**Response:**\n```json\n[\n  {\n    \"symbol\": \"AAPL\",\n    \"name\": \"Apple Inc.\",\n    \"price\": 150.25,\n    \"change\": 2.5,\n    \"volume\": 50000000,\n    \"marketCap\": 2500000000000,\n    \"signal\": \"BUY\"\n  }\n]\n```\n\n### GET `/api/stock/{symbol}`\nFetch and analyze a specific stock\n\n**Example:** `/api/stock/TSLA`\n\n### GET `/api/stocks/cached`\nGet cached stock data from database\n\n## Frontend Usage\n\n1. Open `frontend/index.html` in your browser\n2. Or serve it with a local server:\n\n```bash\ncd frontend\npython3 -m http.server 3000\n```\n\nThen navigate to `http://localhost:3000`\n\n## Technical Indicators\n\n### RSI (Relative Strength Index)\n- Values: 0-100\n- < 30: Oversold (potential BUY)\n- > 70: Overbought (potential SELL)\n\n### Moving Average (20-day)\n- Price below MA: Bearish signal\n- Price above MA: Bullish signal\n\n### Trading Signals\n- **STRONG BUY**: RSI < 30 and Price < MA\n- **BUY**: RSI < 40 and Price < MA\n- **HOLD**: Neutral conditions\n- **SELL**: RSI > 60 and Price > MA\n- **STRONG SELL**: RSI > 70 and Price > MA\n\n## Project Structure\n\n```\nStockAnalyzer/\n├── backend/\n│   ├── CMakeLists.txt\n│   ├── include/\n│   │   ├── api_client.hpp\n│   │   ├── analyzer.hpp\n│   │   ├── data_models.hpp\n│ https://github.com/CrowCpp/Crow/releases/latest/download/crow_all.h -o backend/libs/crow_all.h\n```\n\n**Issue**: libcurl not found\n```bash\nbrew install curl\n```\n\n**Issue**: SQLite not found\n```bash\nbrew install sqlite3\n```\n\n### Runtime Issues\n\n**Issue**: CORS errors in browser\n- Make sure the backend server is running\n- Check that CORS headers are properly set in main.cpp\n\n**Issue**: Empty stock data\n- Check your internet connection\n- Yahoo Finance API might be rate-limiting\n- Try individual stock search instead\n\n## Future Enhancements\n\n- [ ] User
